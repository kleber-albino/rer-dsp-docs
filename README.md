# rer-dsp-docs

Documentação do **DSP (Data Sharing Platform)** do RER.

Site estático gerado com [Zensical / Material for MkDocs](https://github.com/zensical/zensical), publicado via GitHub Pages (GitHub Actions).

## Como publicar

1. Adicione o conteúdo da documentação e o workflow do Zensical.
2. Habilite o GitHub Pages com a fonte **GitHub Actions**.
3. O site é publicado automaticamente a cada push na `main`.
